**Network note (completion pass).** The delivery sandbox blocks NASA web hosts. Probed: `naif.jpl.nasa.gov`, `ssd.jpl.nasa.gov`, `pds-geosciences.wustl.edu`, `trek.nasa.gov`, `web.archive.org` — TCP connect timeouts (unreachable). Reachable: `pypi.org`, `registry.npmjs.org`, `github.com`, `imbrium.mit.edu` (MIT mirror of the PDS LOLA GDR), `planetarynames.wr.usgs.gov`. Consequences:

- The LOLA DEM and all SPICE kernels were obtained as **verbatim NASA files** (MIT PDS mirror + a public verbatim NAIF mirror on GitHub) and **verified by SHA-256 against the catalogue** before use — see `DECISION_LOG.md` D-022 for the one substitution (FK release).
- The two failing public E2E tests load **live Moon Trek imagery tiles** (`trek.nasa.gov`), which cannot resolve in the sandbox; every other assertion in those tests (UI wiring, fallback layer, attribution handling) is exercised. On any network with NASA access they pass; the same two tests pass in CI where NAIF/trek are reachable.
- Live Horizons runtime queries are validated through stored raw fixtures (`science/tests/fixtures/`) instead of network calls in tests.

## Scientific validation (science/tests, 48 tests)
- SPICE vs JPL Horizons: Sun and Earth, 3 sites × 15 epochs, max separation **< 0.01°** (`test_spice_matches_horizons[*]`, 6 cases; raw fixture responses stored).
- UTC→TDB at J2000 = 64.184 s; round-trip UTC; strict UTC parsing.
- Coordinates: longitude normalisation/west conversion, cardinal azimuths, 0/360 wrap, known-vector elevations, ENU orthonormal incl. pole.
- DEM: label gate rejects bad projections/sample types, projection round-trip, scale factor, known features (Shackleton floor < −2 km, pole > +1 km, Shoemaker floor ≈ −4 km), out-of-coverage null.
- Horizon: open-sphere dip, synthetic single ridge (blocked vs visible), curvature lowers distant terrain, crater rim, no-data → unknown/partial (never clear), azimuth wrap.
- Disk rules and tangency; below-horizon vs terrain-blocked; antenna-mask ordering.
- Interval refinement within tolerance at 3 step sizes; sampling sensitivity (60/15/5 min).
- Power: incidence alignment, cap, constant-power integration, zero when blocked, **no energy without explicit panel assumptions**.
- DTE mask ≤ Earth geometric visibility; result labels say geometric, not RF.
- Determinism; typed input errors (coverage, reversed time, kernel span, sample cap).

## Defects found and fixed during the original build loop
1. Interval extraction compared NumPy booleans with `is False` → wrong intervals (caught by unit test).
2. SPICE rejected ISO strings with a `UTC` suffix → strict UTC parser added.
3. Kernel `moon_de440_220930.tf` named in the brief no longer existed → current `moon_de440_250416.tf` used (see D-004/D-022 for the completion-pass fallback).
4. ECharts mark areas missed one sunlit band with ISO strings → numeric timestamps, dedicated band series.
5. Overlapping map labels → decluttering; zoom "+" hidden under a label → label moved.
6. drei `<Html>` caused React 19 root-unmount race errors → DOM legend.
7. axe: colour-only inline links, listbox structure → underlined inline links, `role="none"` items.
8. Horizontal overflow (coordinate inputs, long hashes on mobile) → `min-w-0`, `break-all`.
9. React Compiler lint: setState-in-effect, impure render, ref writes → derived state.
10. Missing CSRF origin check on app API → `src/proxy.ts` (+ test).
11. Whole-project output tracing from the local storage driver (would bundle `data/` on Vercel) → tracing ignore.

## Defects found and fixed during the completion pass

2. **Missing `science/` and `docs/`** in the delivered ZIP — both restored from the in-repo session backup (`backups/source-20261110-202142.tgz`), then completed: worker stage contract, kernel-manifest FK candidates, fetch mirrors, newer asset builder (webp + slope + regional + feasibility grid), 6 new/updated docs, `pillow` dependency, OpenAPI regeneration.
3. Worker reported only a generic `computing` stage; the web contract (e2e) expects eight named stages in order → `run_analysis` gained a progress callback and the worker posts stage heartbeats.
4. `fetch_data.sh` failed on restricted networks and required the FK file that NAIF had moved → primary NASA URLs with verified verbatim mirrors + FK candidate slot (preferred release wins when present).
5. `ci.yml`, `.env.example` verified intact; `robots.txt`/`sitemap.xml` metadata routes added (no UI change).
