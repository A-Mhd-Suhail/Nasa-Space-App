## Validation fixtures

`science/tests/fixtures/horizons_*.txt` and `*.request.json`: raw JPL Horizons observer tables (unaltered) with the exact request parameters and retrieval time.

## Not integrated

NASA Moon Trek WMTS, LROC WAC mosaics, higher-resolution LOLA polar DEMs (5–40 m), live Horizons runtime provider. Registry states support adding these as new immutable product versions.

## Storage key policy (object storage: Supabase Storage in production, filesystem locally)

`analysis/{workspaceId}/{analysisId}/result.json`, `reports/{workspaceId}/{reportId}/v{n}/report.{ext}`, curator uploads `source/uploads/{userId}/{uuid}/{filename}`. Keys are generated server-side; objects are write-once and checksummed.
